# Superstore Sales & Profit Analysis

## 📊 Project Overview

This project analyzes Superstore sales data using SQL Server and Microsoft Power BI to understand sales performance, profitability, regional trends, product categories, and customer segments.

The goal is to transform raw business data into meaningful insights through data analysis and interactive visualization.

## 🛠️ Tools & Technologies

- SQL Server
- Microsoft Power BI
- DAX
- Excel / CSV
- Data Cleaning and Validation
- Data Visualization

## 🔍 Analysis Areas

- Overall sales and profit performance
- Monthly sales trends
- Sales by product category
- Profit by region
- Product profitability
- Discount impact on profit
- Customer segment analysis
- Profit margin analysis

- Sales by Segment chart

## 🎯 Project Objective

To practice SQL-based business analysis and develop an interactive Power BI dashboard that communicates business performance clearly.
